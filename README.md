# slices-terminal README

The puzzle game SLICES, now playable through your VS Code terminal!

## Features

* Two playable games
* 60-second timer
* Score tracking

## Requirements

VS Code

## How to activate

1. Open the Extension Development Host using F5 or "Show and Run Commands > Debug: Start Debugging" in the search bar.
2. Once in the Dev Host, use the search bar to "Show and Run Commands > Slices: Start"
3. SLICES Terminal will begin in the Dev Host's terminal. Press any key to begin playing!

**Enjoy!**
